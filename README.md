## The entry

> I hereby resign as mall Santa: after nine seasons, 4,102 children asked for a new dad this Christmas, and the 4,103rd was my son, Danny.

136 characters. After nine seasons, 4,102 children have all asked Santa for the same thing — a new dad. The twist lands in the last words: the 4,103rd child was his own son, Danny.

## How it works

`main.ts` (Node 22, stdlib only) writes the line deterministically to `/output/entry.txt`. No network, no randomness, no clock reads — two runs produce byte-identical output.
